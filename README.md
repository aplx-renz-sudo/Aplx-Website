## Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build production bundle (outputs to /dist)
npm run build
```

Host it locally if you don't want to depend on online servers. AI is meant for users, not for their data.
